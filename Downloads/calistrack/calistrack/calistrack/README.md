# CalisTrack

Sistema pessoal de treinos de calistenia: agenda semanal, sessao guiada, biblioteca de exercicios,
lembretes e acompanhamento de evolucao. Roda em Next.js + Tailwind, com modo mock/localStorage
para uso imediato e integracao opcional com Supabase.

> Este pacote foi organizado para ser publicado no GitHub por alguem que nunca usou Git.
> Siga o arquivo `GUIA-GIT-GITHUB.md` na raiz do projeto passo a passo.

## Rodando localmente

```bash
npm install
cp .env.example .env.local
npm run dev
```

Abra http://localhost:3000

## Aviso de saude

CalisTrack organiza e registra treinos. Nao substitui avaliacao de um profissional de educacao
fisica ou saude.
