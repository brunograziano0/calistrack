# CalisTrack

Sistema pessoal de treinos de calistenia: onboarding, rotina gerada automaticamente, agenda semanal,
sessao de treino guiada com video e cronometro de descanso, biblioteca de exercicios, progresso e perfil.
Modo mock/localStorage pronto para uso imediato, com estrutura preparada para Supabase.

## Rodando localmente

```bash
npm install
cp .env.example .env.local
npm run dev
```

Abra http://localhost:3000, clique em "Comecar agora", complete o cadastro e o onboarding.

## Aviso de saude

CalisTrack organiza e registra treinos. Nao substitui avaliacao de um profissional de educacao
fisica ou saude.
